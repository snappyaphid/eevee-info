Privacy policy

Last updated 22 October 2026

Eevee is a personal assistant used only by its owner. This page describes what it does with the owner's Google account data.

What it accesses

  • Gmail, with read-only permission (gmail.readonly). It reads new emails as they arrive.
  • It never sends, replies to, forwards, deletes, archives or marks emails as read. It does not have permission to, and its code refuses those requests.
  • The owner's YouTube channel, with read-only permission (youtube.readonly and yt-analytics.readonly). Once a day it reads the channel's statistics, each video's statistics, the channel's analytics reports (views, watch time, subscribers and traffic sources) and recent public comments.
  • It never uploads, edits, deletes, comments, replies, likes or moderates anything on YouTube. It does not have permission to, and its code refuses those requests.

What it does with it

  • Each new email's text is sent to the Anthropic Claude API to be sorted and summarised in one or two lines.
  • Summaries of important emails are sent to the owner's own phone through a private Telegram bot.
  • Eevee keeps the sender, subject, its own summary and a link on the owner's computer. It does not keep email bodies.
  • YouTube figures and recent comments are stored on the owner's computer and shown on the owner's private dashboard. They are refreshed daily, and the daily channel totals are kept so the dashboard can show trends.
  • YouTube statistics and comments may be sent to the Anthropic Claude API to be summarised (grouping comments by theme, and a weekly takeaway), the same way emails are.
  • To find video clips, Eevee sends links to public YouTube videos, with their public comments and a description of the kind of clip wanted, to the Google Gemini API, which watches and listens to the video and describes it. No Gmail, private YouTube data or analytics are sent to Gemini.
  • Eevee uses Gemini's free tier, so under Google's Gemini API terms Google may use what it is sent to improve its products. Only public videos and comments are sent.
  • Nothing is sold, shared or used for advertising, and no one other than the owner sees it.

YouTube

Eevee uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Google API Services User Data Policy

Eevee's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. When access is removed, Eevee stops reading, and the owner can delete the stored copies from their own computer.
